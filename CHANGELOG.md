# Release notes

## 0.3.1

- Settings includes an anonymous, user-triggered stable-release version check and reviewed manual source-update instructions.
- Windows desktop with crimson/black branding, bundled Manrope, Sora and JetBrains Mono fonts, reduced motion, Home, Settings, Documentation and Release Notes.
- Multiple editable repository workspaces; GitHub device authorization and protected saved sessions; no user Client ID entry.
- Exact-file dry-run and explicitly authorized automatic synchronization, audit activity and remote verification.
- One active automatic session, tray Open/Stop/Exit, local Git calendar and commit diffs.

Limitations: public GitHub App onboarding has not been verified; GitLab/Bitbucket, empty-repository initialization, recovery UI, signed installers and automatic update installation are not included. Windows source distribution requires Python/Tkinter and Git.
